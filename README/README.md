
# Mini-Courier Planner

## Project Overview
A Python-based DAA project that optimizes parcel selection and delivery routes using different algorithms.

## Algorithms Used

1. Merge Sort
2. 0/1 Knapsack using Dynamic Programming
3. Dijkstra's Shortest Path Algorithm
4. Nearest Neighbor TSP Approximation

## Project Structure

- data/: Contains parcel and graph data
- outputs/: Contains generated runtime charts
- courier_planner.py: Main Python program
- README.md: Project documentation

## Technologies Used

- Python
- JSON
- Matplotlib

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Install Matplotlib:

   pip install matplotlib

5. Run:

   python courier_planner.py
